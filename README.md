# Was it the bank, or the economy?

Credit risk and share-price reaction for State Bank of India and Federal Bank against peers, FY14 to FY25.
One self-contained `index.html` (data, code, chart library and fonts inlined; works offline).

**Status: work in progress.** Credit figures are complete for SBI only. See the Data and sources tab for every figure and its source.

## Host on GitHub Pages
1. Create a new public repository on github.com (for example `fra-credit-risk`).
2. Click **Add file > Upload files** and drag in `index.html`, `README.md` and `.nojekyll`. Commit.
3. Go to **Settings > Pages**. Under Source choose **Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

If `.nojekyll` does not show after upload (hidden files), create it in the browser: **Add file > Create new file**, name it `.nojekyll`, commit.
